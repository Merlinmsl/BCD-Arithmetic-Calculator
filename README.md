# Introduction

Digital Electronic is the backbone of computing today and with the arithmetic operations forming the basis of their functioning. Of all the number systems used in digital electronics, Binary Coded Decimal(BCD) gives a unique representation in which each of the decimal digits is represented by four binary bits. This scheme represents up to the decimal value 9 and higher values represent using the remaining four bits. This allows easier conversion between human-readable decimal values and machine-level binary data, making BCD particularly useful in systems like digital clocks, calculators, and financial applications where decimal precision is critical.

This project focuses on the design and simulation of a Mini-Processor capable of performing arithmetic operations Addition, Subtraction, and Multiplication on 2-digit BCD inputs. The objective is to deepen the understanding of BCD arithmetic, circuit-level logic design, and the integration of control logic to enable flexible operation selection based on input signals.

The designed system accepts two single-digit BCD numbers and a 2-bit control input to determine the operation to be performed. The output consists of a 2-digit BCD result along with an overflow flag to indicate if the result exceeds the 2-digit limit (i.e., greater than 99). Through this assignment, students will gain practical experience in designing individual arithmetic units, simulating their behavior using Proteus software, and integrating them into a fully functional digital processor.
